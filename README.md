# Clock (PWA)

아이폰·아이패드용 풀스크린 시계. Safari에서 열거나 홈 화면에 추가해 사용합니다.

## 개발

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
npm run preview
```

## 사용

1. 화면을 탭하면 설정이 열립니다.
2. **기능 → 모드**에서 시계 / 뽀모도로 / 스톱워치를 고릅니다.
3. 뽀모도로는 기본 25분이며, 분 단위로 바꿀 수 있습니다.
4. 시작·일시정지·리셋은 화면 아래 버튼으로 조작합니다.
5. iOS Safari: 공유 → **홈 화면에 추가**로 설치형(PWA)처럼 사용합니다.

## 저전력 참고

- 초/아날로그가 꺼져 있으면 **분 단위**로만 갱신합니다.
- 탭이 백그라운드면 타이머를 멈춥니다.
- **화면 켜두기**는 기본 OFF입니다 (Wake Lock).

## 디바이스 검증 체크리스트

- [ ] iPhone Safari: 세로/가로에서 시계가 화면을 채움
- [ ] iPad Safari: 큰 화면에서도 가독성 유지
- [ ] 홈 화면 추가 후 standalone으로 열림
- [ ] 초 OFF → 분이 바뀔 때만 갱신
- [ ] 설정 변경 후 새로고침해도 유지
- [ ] 오프라인에서도 캐시된 앱 로드 (SW)
